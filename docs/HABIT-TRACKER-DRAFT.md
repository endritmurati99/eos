# Habit Tracker

## Zweck
Diese Datei hält EOS-Habits getrennt von Tasks.

## Regeln
- Habits sind keine Tasks.
- Habits laufen unabhängig von Google Tasks.
- EOS nutzt diese Datei als stabile Referenz für Gewohnheiten und Reflexion.
- Änderungen an Habits sollen bewusst und sparsam erfolgen.

## Aktive Habits

### Hängenlassen an der Klimmzugstange
- Status: aktiv
- Frequenz: täglich
- Check-Zeit: 21:00
- Typ: Habit / körperliche Gewohnheit
- Ziel: Konsistenz aufbauen

#### Abendlicher Check
- Wie war dein Tag?
- War dein Tag erfolgreich?
- Was hätte besser laufen können, damit du dich weiter verbesserst?

#### Notizen
- Habit bewusst getrennt von Aufgabenverwaltung halten.
- Fokus auf Reflexion und Konsistenz, nicht auf Task-Abhaken.
