# EOS Templates

Files in this directory define how EOS should:
- ingest brain dumps
- generate daily plans
- generate weekly plans
- maintain vault notes for the EOS second-brain layer

Planner output templates:
- `daily-output.md`
- `weekly-output.md`
- `evening-reset-output.md`
- `weekly-review-output.md`
- `manual-task-intake.md`

Vault / second-brain templates:
- `brain-dump-intake.md`
- `brain-dump-note.md`
- `daily-note.md`
- `project-note.md`
- `idea-note.md`

Important separation:
- `daily-output.md` = operational daily planning response
- `evening-reset-output.md` = proactive evening message for tomorrow
- `daily-note.md` = durable vault note for Tagesstand, session continuity, and Verlauf
- `weekly-output.md` = interactive weekly planning response
- `weekly-review-output.md` = Sunday combined review + next-week sync output

Current non-template vault areas without dedicated templates in this change:
- `13 Areas`
- `14 Knowledge`
